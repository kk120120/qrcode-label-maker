Python 批量二维码标签生成器 - 设计文档

1. 项目概述

本项目是一个用于生成批量二维码标签的工具，支持自定义标签大小、二维码属性和文本属性，并能通过CSV导入数据进行批量生成。

版本：v0.7.2

GitHub 项目地址：https://github.com/kk120120/qrcode-label-maker

3. 模块说明

MainWindow

主要用途：应用程序的主窗口，负责整体布局和用户交互管理。

主要方法：

  • init_ui()：初始化用户界面
  • open_basic_settings()：打开基础设置对话框
  • on_qr_button_clicked()：处理二维码按钮点击事件
  • on_text_button_clicked()：处理文本按钮点击事件
  • on_save_properties()：保存对象属性
  • update_property_panel()：更新属性面板
  • export_current()：导出当前标签
  • batch_export()：批量导出标签

触发条件：

  • 用户启动应用程序
  • 用户点击工具栏按钮
  • 用户修改属性面板中的值
  • 用户选择导出功能

LabelDesigner

主要用途：标签设计区域，负责绘制标签和对象，处理用户的鼠标交互。

主要方法：

  • paintEvent()：绘制标签和对象，包括对象类型简称和序号
  • mousePressEvent()：处理鼠标按下事件，更新选中对象和属性面板
  • mouseMoveEvent()：处理鼠标移动事件，实现对象拖动
  • mouseReleaseEvent()：处理鼠标释放事件
  • keyPressEvent()：处理键盘事件
  • add_qr_object()：添加二维码对象
  • add_text_object()：添加文本对象
  • update_object_properties()：更新对象属性

触发条件：

  • 用户在设计区域点击
  • 用户拖动对象
  • 用户按下键盘按键
  • 用户添加新对象

LabelTemplate

主要用途：标签模板管理，负责存储和管理标签的尺寸、DPI和对象信息。

主要方法：

  • set_label_size()：设置标签尺寸
  • set_dpi()：设置DPI
  • add_qr_object()：添加二维码对象
  • add_text_object()：添加文本对象
  • update_object()：更新对象属性
  • remove_object()：删除对象
  • save_template()：保存模板到文件
  • load_template()：从文件加载模板

输入输出参数：

add_qr_object：
输入：x, y, width=10, height=10, qr_version="21x21", error_correction="Q", content="", batch=False, csv_column=""
输出：obj_id (字符串)
add_text_object：
输入：x, y, width=30, height=10, font="Arial", font_size=3, font_style=["normal"], color="#000000", content="", batch=False, csv_column=""
输出：obj_id (字符串)
update_object：
输入：obj_id, **kwargs (包含x, y, width, height, properties等)
输出：bool (是否更新成功)

PropertyPanel

主要用途：属性面板，用于显示和编辑选中对象的属性，包括对象类型和序号。

主要方法：

  • show_qr_properties()：显示二维码属性
  • show_text_properties()：显示文本属性
  • update_csv_columns()：更新CSV列选择
  • update_capacity()：更新二维码容量显示

新增功能：

  • 显示选中对象的类型和序号
  • 实时更新属性面板信息

CSVHandler

主要用途：CSV文件处理，负责导入和管理CSV数据。

主要方法：

  • import_csv()：导入CSV文件
  • get_columns()：获取CSV列名
  • get_data()：获取CSV数据
  • get_preview_data()：获取CSV预览数据

ImageProcessor

主要用途：图像处理，负责创建和导出标签图像。

主要方法：

  • create_label()：创建标签图像
  • add_qr_to_label()：向标签添加二维码
  • add_text_to_label()：向标签添加文本，支持逐字计算换行
  • save_label()：保存标签图像
  • batch_process()：批量处理标签

新增功能：

  • 支持逐字计算文本换行，确保文本不超出文本框宽度
  • 支持处理UTF-8 with BOM格式的文本
  • 优化字体加载逻辑，优先使用系统中常见的中文字体路径

QRGenerator

主要用途：二维码生成，负责生成二维码图像。

主要方法：

  • generate_qr()：生成二维码图像，支持根据qr_size参数计算版本

输入输出参数：

generate_qr：
输入：content (字符串), error_correction (字符串), qr_size (字符串，默认为"21x21")
输出：PIL Image 对象

新增功能：

  • 支持根据qr_size参数计算二维码版本
  • 确保版本在有效范围内（1-40）

ConfigManager

主要用途：配置管理，负责读取和管理配置文件。

主要方法：

  • get_qr_sizes()：获取二维码尺寸列表
  • get_capacity()：获取二维码容量信息

4. 特殊要求说明

特殊要求

  • 支持批量生成二维码标签
  • 支持CSV数据导入

5. Bug和优化日志

Bug 日志

1. 坐标和尺寸小数问题

问题：拖动对象时位置跳动，偏上偏下

原因：使用int()转换导致坐标精度丢失

解决方案：移除int()转换，内部使用小数存储，绘制时再转换为整数

2. PyQt6 QAction导入错误

问题：PyInstaller打包时出现QAction导入错误

原因：PyInstaller对PyQt6的支持不完善

解决方案：从PyQt6切换到PyQt5

3. GitHub Actions Node.js 20 deprecation warning

问题：GitHub Actions构建时出现Node.js 20弃用警告

解决方案：添加FORCE_JAVASCRIPT_ACTIONS_TO_NODE24=true环境变量

4. 批量生成崩溃

问题：批量生成时程序崩溃

解决方案：在批量复选框事件处理中添加try-except块

5. 文本编码问题

问题：文本内容编码不正确

解决方案：添加显式字符串转换

6. CSV预览不更新

问题：CSV预览数据不更新

解决方案：更新update_preview()方法，清空并重新加载数据

7. 属性面板不更新

问题：创建新对象后，再点击之前的对象，属性面板不更新

解决方案：修改mousePressEvent方法，确保点击对象时强制更新属性面板

8. 文本超出文本框边界

问题：文本内容超出文本框宽度，导致显示不完整

解决方案：实现逐字计算文本换行，确保文本不超出文本框宽度

9. 中文文本乱码

问题：导出的图片中中文文本显示乱码

解决方案：优化字体加载逻辑，优先使用系统中常见的中文字体路径，并处理UTF-8 with BOM格式的文本

10. 批量生成进度窗显示时机

问题：批量生成进度窗在对话框打开时就显示，而不是在点击开始后

解决方案：修改批量生成逻辑，在点击开始按钮后才创建和显示进度窗

效果：用户可以进行更精细的位置和尺寸调整

效果：用户在输入框中输入值后按回车键即可更新属性

5. 显示对象类型和序号

优化内容：简化点击检测逻辑，确保点击对象时正确更新属性面板

效果：文本内容自动换行，不会超出文本框边界

优化内容：在点击开始按钮后才显示进度窗，提高用户体验

效果：进度窗在批量生成开始时才显示，符合用户预期
