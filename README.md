# Python 批量二维码标签生成器

## 0 背景记录
在互联网上找不到一款免费使用，满足如下需求的软件；

- 支持批量CSV 内容生成 QR码
- 支持用户自定义标签尺寸、设计二维码/文本元素
- 实现单张/批量二维码标签PNG导出，满足标签打印、批量生成场景需求。
- 草料，标签模板不可以自由创建，没找到刚好合适的。

尝试豆包生成一个，人工测试和检查。

## 项目概述

这是一款基于PyQt5开发的桌面端标签设计工具，支持用户自定义标签尺寸、设计二维码/文本元素、绑定CSV数据，实现单张/批量二维码标签PNG导出，满足标签打印、批量生成场景需求。

## 核心特性

- **毫米(mm)为单位的标签精准设计**，支持DPI自定义
- **可视化拖拽编辑**，支持鼠标/键盘微调元素位置
- **二维码参数可配置**（尺寸、纠错等级、数据容量实时提示）
- **文本对象全样式自定义**（字体、大小、颜色、样式）
- **CSV数据导入、预览、批量绑定**
- **模板本地保存/加载**
- **单张导出、批量PNG导出**

## 技术栈

- **开发语言**：Python 3.8+
- **GUI框架**：PyQt5
- **二维码生成**：qrcode、Pillow
- **配置解析**：configparser
- **文件处理**：csv、os、json
- **数据处理**：pandas

## 使用教程

### 1. 基础设置

- 点击菜单栏 **设置 → 基础设置**
- 设置标签尺寸（宽度、高度、圆角）
- 设置DPI（96-600之间）
- 点击确定保存设置

### 2. 添加元素

- **二维码对象**：点击左侧工具栏的"矩形QR对象"按钮，然后在标签设计区点击添加
- **文本对象**：点击左侧工具栏的"多行文本对象"按钮，然后在标签设计区点击添加

### 3. 编辑元素属性

- 点击选中元素
- 在右侧属性面板修改属性：
  - **基本属性**：位置、尺寸
  - **二维码属性**：尺寸、纠错级别、内容、批量生成
  - **文本属性**：字体、大小、样式、颜色、内容、批量生成
- 点击"保存"按钮应用更改

### 4. 导入CSV数据

- 点击菜单栏 **数据 → 导入CSV**
- 选择CSV文件
- 在预览对话框中查看数据
- 点击"确认"完成导入

### 5. 批量生成设置

- 选中需要批量生成的元素
- 在属性面板勾选"批量生成"
- 选择要绑定的CSV列
- 点击"保存"按钮

### 6. 导出标签

- **单张导出**：点击菜单栏 **导出 → 导出当前标签为PNG**
- **批量导出**：点击菜单栏 **导出 → 批量导出**，选择输出文件夹

### 7. 模板管理

- **保存模板**：点击菜单栏 **文件 → 保存模板**
- **打开模板**：点击菜单栏 **文件 → 打开**
- **新建模板**：点击菜单栏 **文件 → 新建**

## 注意事项

- 批量导出功能需要先导入CSV文件
- 批量导出时，文件名使用二维码内容前12个字符
- 标签对象超出边界时会显示红色边框
- 支持Windows系统字体选择
- DPI修改后，所有元素像素自动重新计算，保持物理尺寸不变

## 示例

1. 创建一个50mm×30mm的标签
2. 添加一个二维码对象和一个文本对象
3. 导入包含产品信息的CSV文件
4. 将二维码绑定到"url"列，文本绑定到"product_name"列
5. 批量导出所有产品的标签
